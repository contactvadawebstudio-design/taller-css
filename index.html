          Las 8 cosas que rompen un CSS
          
      
          
        
            
          
          • 1. Forma de la reglaselector { propiedad: valor; } Dos puntos, nunca =.
            • 
          
          • 2. Punto y coma al finalSin el, esa declaracion y la siguiente se pierden juntas.
            • 
          
          • 3. Cada { con su }Una llave sin cerrar se come las reglas de debajo.
            • 
          
          • 4. Unidad pegada al numerobien 20px · mal 20 px o 20. Solo el 0 va sin unidad.
            • 
          
          • 5. Todo en inglescolor: gray; text-align: center; Ni gris ni centre.
            • 
          
          • 6. Clase con punto, id con #.aviso #portada. Nunca empiezan por numero.
            • 
          
          • 7. Hex de 3 o 6 cifras#f60 #ff6600. Decimales con punto: 0.5.
            • 
          
          • 8. link con href<link rel="stylesheet" href="estilos.css"> dentro del head.
            • 
        
          
      
          
    
          

    
          
      
          Examen en ordenador: rutina del dia
          
      
          
        
          01
          Escribe las llaves antes que el contenido. Tecleas h1 { }, Enter en medio, y rellenas. Asi es imposible dejarse una llave abierta.
          
        
          02
          Una declaracion por linea, sangrada. Un punto y coma olvidado se ve a simple vista cuando todas las lineas acaban igual.
          
        
          03
          Guarda y recarga el navegador cada poco. F5 despues de cada regla. Si algo no cambia, el fallo esta en lo ultimo que has escrito.
          
        
          04
          Si algo no se aplica, Inspeccionar. Clic derecho sobre el elemento. Lo que el navegador no entiende sale tachado o con un triangulo amarillo.
          
        
          05
          Mira que la clase se llama igual en los dos sitios. class="aviso" en el HTML y .aviso en el CSS, con las mismas mayusculas.
          
        
          06
          Comprueba el href del link. Si el CSS no se aplica nada, casi siempre es la ruta o el nombre del fichero.
          
        
          07
          Reparte el tiempo antes de teclear. Lee el enunciado entero, cuenta los apartados y deja los dos ultimos minutos para releerlo frase a frase contra tu pagina.
          
        
          08
          Apunta lo que diga el profesor de palabra. Nombre de los ficheros, si quiere el CSS aparte, si pide comentario con tu nombre. Eso no lo ve ningun revisor.
